24시누수케어 앱 제작 파일

구성
- index.html: 기존 고객관리·작업일지·매출관리 프로그램
- manifest.webmanifest: 앱 이름/아이콘/화면 설정
- service-worker.js: 오프라인 캐시 설정
- icons/: 앱 아이콘

중요
이 압축파일은 앱 제작용 원본 프로젝트이며, APK 설치 파일 자체는 아닙니다.
휴대폰 홈 화면 설치(PWA) 또는 APK 변환을 하려면 먼저 HTTPS 주소로 웹에 올려야 합니다.
파일을 휴대폰 파일관리자에서 바로 여는 것만으로는 PWA 설치나 오프라인 캐시가 정상 작동하지 않습니다.

스마트폰만으로 진행하는 다음 단계(개요)
1. 갤럭시 인터넷/크롬에서 GitHub 또는 Netlify에 접속해 계정을 만들고 로그인합니다.
2. 이 프로젝트의 파일들을 웹사이트로 게시해 HTTPS 주소를 만듭니다.
3. 게시된 주소를 크롬에서 열고 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
4. APK가 꼭 필요하면 게시된 HTTPS 주소를 이용해 PWA 패키징 서비스를 통해 Android 패키지를 생성하고, 생성된 APK를 내려받아 설치합니다.

데이터 주의
이 앱은 브라우저 내부 저장소를 사용합니다. 앱/브라우저 저장공간을 지우거나 앱을 제거하면 데이터가 사라질 수 있습니다.
고객정보를 입력하기 전에 앱의 백업 기능으로 JSON 백업을 자주 저장하세요.
휴대폰과 PC는 별도 저장소이므로 자동 동기화되지 않습니다.
